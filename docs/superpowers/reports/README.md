# Comptes rendus de vague

Un fichier par vague d'un chantier livré par vagues, écrit par l'orchestrateur de la vague : `<AAAA-MM-JJ>-<chantier>-vague-<N>-compte-rendu.md`. Le chantier est dans le nom, pour que deux chantiers ne s'y marchent pas dessus ; la date est celle où le fichier s'ouvre.

**Chantier « Économie unifiée et catalogue »** — `<AAAA-MM-JJ>-economie-et-catalogue-vague-<N>-compte-rendu.md`. Ce qu'un compte rendu contient, et pourquoi il est écrit plutôt que dit, est fixé par le [fichier d'orchestration](../../possible_upgrades/01-10-2026_orchestration_chantier_economie_et_catalogue_Fable5.md), §3.8 : la branche et ses chiffres, la table des arbitrages, le cahier de test manuel, le résultat de la simulation, ce qui a été trouvé périmé. Il s'ouvre à la fin du premier plan de la vague, par sa table des arbitrages (§3.5), et se complète avant qu'elle s'arrête ; la session de correction (§3.10) le relit et le complète.

Le récit non technique de ce que la vague apporte au jeu n'est pas ici : il est dans le suivi du chantier, sous [`docs/suivi_vagues_chantier/`](../../suivi_vagues_chantier/) — pour ce chantier, [`economie_unifiee_et_catalogue.md`](../../suivi_vagues_chantier/economie_unifiee_et_catalogue.md).
