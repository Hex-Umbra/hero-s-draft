# Archives de la chaîne pixel art

Les versions remplacées et les essais abandonnés, gardés pour mémoire. **Lecture seule :** on n'y retouche rien, et aucun outil n'y lit.

**Rangement :** `<id>/<date>_<ce que c'est>/`, où `<id>` est celui de la créature ou du fond. Les fichiers gardent leur nom d'origine.
